# STUDENT-HUB

    A fullstack student productivity and learning platform built to bring everyday tools into one place

It is a fullstack web app designed for studnets who wants to manage their tasks,courses,learning roadmaps and progress from a single platform .

the project startd as a frontend react app and evolve into a fullstack app with node/express backend , auththentication,database
and CURD APIs.

# FEATURES

    # Courses Roadmap - find and explore different roadmaps of various courses.
    # ToDo - CURD tasks for daily activity.
    # Calculator - fast track your calculations
    # Progress - track your everyday progress
    # Authentication - register/login to maintian your privacy.

# TECH STACK

    Frontend - react,vite,javascript,html,css,tailwind css,react router,axios
    Backend - node,express,REST api,JWT based authentication,bcrypt,CORS
    Database - Mongo DB , JSON data file
